Login and logout events now record the footage that was airing when they happened, filling the `video_id` / `video_ts_sec` columns migration 044 added. Per-clip join/leave churn — which footage holds an audience and which sheds it — becomes a `GROUP BY` over `events` instead of an interval-pairing join against `video_plays`. `Sessions` takes an optional `VideoSource`, wired in `cmd/tripbot` from the process-wide player; an instance that isn't driving playback writes NULL rather than clip 0.
