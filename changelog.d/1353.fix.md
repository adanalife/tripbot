**The silent-disconnect watchdog no longer retries a failing stream restart every tick.** The cooldown was stamped only after a restart succeeded, so a recovery that kept failing had no timestamp to measure against and re-fired on every 60s tick — 24 rejected `StartStream` calls in 9 hours on one prod incident, each re-stopping an OBS output that was already mid-teardown. The attempt is stamped when it's made, so the cooldown now governs the case it was written for.
