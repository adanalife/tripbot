Every overlay's state is now guarded by a lock. Each onscreen runs a background loop that hides it once its display window closes, while the HTTP and NATS handlers set its content from their own goroutines — all of them were touching the same fields unsynchronised, so a `!timewarp` landing as the sweeper ran could leave an overlay showing stale content, showing empty, or stuck visible. The state endpoint the OBS browser sources poll now serves a consistent snapshot rather than a struct being written underneath it.
