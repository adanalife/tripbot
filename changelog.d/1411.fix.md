The shutdown sequence no longer names a phantom file when nothing ever played. It logged `last played video` unconditionally, and since a filename is the clip's slug plus `.MP4`, a run that died before the player resolved a clip reported `file=.MP4` as if that were the last thing on screen. Shutdown logs are exactly what gets read after a crashloop, so that case now logs `no video played this run` instead; the existing line and its `file` attribute are unchanged whenever a clip did play.
