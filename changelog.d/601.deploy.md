- **Explicit trace sampling policy on the OTel TracerProvider** — `ParentBased(TraceIDRatioBased(0.1))`, replacing the SDK's `AlwaysSample` default. `ParentBased` honors a propagated decision, so a sampled request stays sampled the whole way across tripbot → vlc-server → onscreens-server; only standalone roots, such as cron ticks and a chat-command dispatch with no HTTP parent, are subject to the 10% draw. The rate is a single constant, set conservatively against Grafana Cloud's 50 GB/14-day trace ingest.
