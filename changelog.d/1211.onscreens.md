Corner-rotator overlay copy is now editable per platform from the admin console instead of hardcoded in the binary. Postgres holds the copy, tripbot's new `/api/rotators/{platform}` serves and saves it, and a save pushes it to that platform's onscreens-server over NATS — no redeploy, no restart. Each platform starts prefilled from the copy that shipped in the binary, and can be reset back to it.
