Stop redialing EventSub when Twitch rejects the broadcaster token. A 401 on every subscription is permanent until someone re-consents, but the reconnect loop retried it every ~20s (Twitch drops a subscription-less session with close code 4003), logging five errors a cycle. `Run` now returns `ErrUnauthorized` in that case and the caller stops with an actionable message. A token that only lacks one event type scope still keeps the subscriptions it got, and still reconnects.
